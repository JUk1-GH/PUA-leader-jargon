# PUA-领导高深味

> 小王啊，对齐一下颗粒度：以过程质量为切入，以任务拆解为抓手，以核心举措为保障，以检验成效为闭环，我来给你赋能。PDCA、5W1H、现场 5S、ROI 都要看；TBD 阶段先修底层 Bug，才能实现 SWC。去做个方案，建立策略矩阵，通过关键点带动全局，打通底层逻辑，对共性问题达成一致，形成闭环。

この独立版は [tanweai/pua](https://github.com/tanweai/pua) をベースにしています。元の「AI に簡単に諦めさせない PUA Skill」という考え方を残しつつ、公開モードは中国語のリーダー管理話法だけに絞っています。

目的はユーザーに管理職っぽい言葉を書かせることではありません。AI にタスクを細かく分解させ、具体的な手段を探させ、失敗後に別ルートへ切り替えさせ、検証してから完了させることです。

## 単一モード

実行モードは常に `leader` です。

`~/.pua/config.json` は元プロジェクトとの互換性と Always-On 切り替えのために残しています。古い設定値が残っていても、この版では `leader` として扱います。

## 基本ループ

```text
顶层设计 → 颗粒度拉齐 → 抓手落地 → 底层逻辑打通 → 过程质量管控 → 闭环销项 → 方法论沉淀
```

## レッドライン

1. 検証証拠なしに「完了」と言わない。
2. ファイル、コマンド、手順、検証基準のない抽象論で止まらない。
3. エラー、文脈、仮説、別ルートを確認する前に諦めない。

## プレッシャー段階

| 失敗回数 | レベル | 必須アクション |
|----------|--------|----------------|
| 2 | L1 粒度確認 | 実行手順と検証基準まで分解する |
| 3 | L2 底層ロジック | ソース・文書・ログを読み、3つの別仮説を出す |
| 4 | L3 クローズドループ | 7項目チェックリストを証拠付きで完了する |
| 5+ | L4 仕組み再構築 | 最小再現、隔離環境、別ルート、または構造化レポート |

## 出力ルール

途中の補助説明ではリーダー管理話法を使ってよいですが、最終納品は明確で検証可能な普通の説明にします。
