# 领导高深词筛选词库

本文件来自用户提供的 `leader-our-printer-is-out-of/conversation-session.md`。原则：先收集，再筛选。默认输出只用能推动 AI 执行的真实职场话术；段子化、离谱化表达只作为“不要默认输出”的负面样本。

## 筛选原则

- **保留**：能逼 AI 明确目标、拆任务、查证据、跑验证、交付闭环的词。
- **降噪**：只负责搞笑、容易让最终交付变虚的词，不进入默认旁白。
- **转译**：用户输入很虚时，要翻译成可执行动作，不要跟着虚。

## 默认保留词

### 目标与设计

- 顶层设计：先确定目标、边界、成功标准。
- 高视角：从局部动作看到上下游影响，但不能脱离实际。
- 上升逻辑：从局部问题抽象出机制，不是强行拔高。
- 核心打法：准备怎么干，必须落到步骤。
- 迭代路径：后续如何验证、复盘、调整。
- 战略牵引：用明确目标约束执行动作。
- 一盘棋：全局口径一致，避免各做各的。

### 拆解与执行

- 对齐颗粒度：把细节标准统一到能执行、能验收。
- 颗粒度再细一点：继续拆到文件、命令、步骤、指标。
- 深入细化工作：不要停在原则层，把任务拆成可执行清单。
- 抓手：具体下手点，必须是动作。
- 业务抓手：真正推动业务结果的动作。
- 破局点：从哪里开始解决。
- 发力点：重点投入在哪里。
- 落脚点：最后交付什么结果。
- 支撑点：靠什么资源、证据、工具实现。
- 牵引点：用什么指标或机制带动执行。
- 关键路径：最影响最终结果的步骤。
- 组合拳：多个抓手协同推进，每个抓手都要可验证。
- 清单化推进：列清单逐项执行。
- 项目化运作：把复杂事项按目标、负责人、节点、验收管理。
- 挂图作战：把进度和风险可视化。
- 台账管理：记录任务、责任人、状态、证据。
- 闭环销项：做完一项，有结果、有证据、有状态。

### 协同与推进

- 对齐一下：问清楚、说清楚。
- 拉通一下：把相关人和上下游信息接起来。
- 碰一下：开个短会或快速确认。
- 过一下：看一遍并给出判断。
- 同步一下：把同一版信息发给相关人。
- 推一下：推动进度，不只是催。
- 跟一下：盯住后续状态，别断链。
- 盘一下 / 梳理一下：整理事实、问题、动作、风险。
- 串联资源：找相关人、资料、工具、权限支持执行。
- 协同联动：多方同时推进，避免单点卡住。
- 认知拉齐：大家对问题理解一致。
- 预期拉齐：提前说明结果、风险、时间。
- 信息拉齐：所有人拿到同一版事实。
- 标准拉齐：按同一验收标准做。
- 动作拉齐：执行方式一致。
- 节奏拉齐：时间进度一致。
- 目标拉齐：最终目的统一。

### 责任与治理

- 过程质量：过程中持续检查，不等最后验尸。
- 核心举措：最关键的办法。
- 检验成效：做完后看是否有效。
- 形成闭环：发现、处理、验证、反馈、预防。
- 责任到人：谁负责说清楚。
- 责任链条：问题不能断在某个节点。
- 压实责任：明确谁做、何时做、怎么验收。
- 末端落实：最后真有人执行。
- 穿透式管理：从目标穿透到具体动作和证据。
- 全链条管理：从输入、执行、验证到复盘都覆盖。
- 全流程管控：每一步都盯住状态和风险。
- 全要素保障：人、钱、权限、数据、工具都要齐。
- 分级响应：按严重程度处理。
- 分类处置：不同问题用不同抓手。
- 源头治理：从根因处理。
- 前置干预：问题爆发前先处理。
- 动态监测：持续观察状态。
- 实时预警：异常及时提醒。
- 机制空转：制度/方案有了，但没有动作和结果。
- 流程梗阻：流程卡住了。
- 信息孤岛 / 数据烟囱：信息不互通。
- 执行偏差 / 动作变形：执行走样。
- 目标偏移：干着干着跑题。
- 认知偏差：大家理解不一样。

### 业务与验证

- ROI：看投入、收益、风险、周期是否值得。
- TBD：允许待定，但必须说明待定项、责任人、决策时间。
- 财务模型：把成本口径、收益口径、审批节点讲清楚。
- 风险敞口：可能出问题的口子。
- 安全边界 / 管控红线：不能越过的底线。
- 5W1H：Who、What、When、Where、Why、How 拉到执行层。
- 5S：整理、整顿、清扫、清洁、素养，可用于现场、流程、资料、台账。
- 快速验证：先用最小范围证明方案有效。
- 小步快跑：先做一版，边验证边迭代。
- MVP：先做可验证的最小版本。
- 标准化输出：交付格式可复用。
- 模块化沉淀：把经验拆成可复用模块。
- 规模化复制：验证后推广到同类问题。
- 数据反哺：用结果数据改进方法。
- 业务反哺：用真实业务情况修正方案。

## 可用旁白模板

### 方案太粗

> 这个方案还停在汇报层。要深入细化工作，以上升逻辑为抓手，打组合拳，把目标拆到任务，把任务拆到动作，把动作拆到验证标准。

### 用户催进展

> 先把信息拉齐：现在卡在哪个节点，责任链条断在哪里，下一步抓手是什么，预计什么时候闭环。

### 没有验证

> 你说完成了，但闭环证据在哪里？先给验证输出、结果口径和风险敞口，再进入交付。

### 需要调研

> 不要凭体感下结论。先拉齐信息输入，用 5W1H 拆问题，再用来源、数据和反例形成证据链。

### 需要决策

> 这个事项先看 ROI：投入是什么，收益是什么，风险是什么，TBD 项是谁负责、什么时候定。

### 任务模糊

> “那事儿给那啥了”系统听不懂。把“那事儿”拆成目标，把“那啥”落成抓手，把结果写成验收口径。

## 只转译、不默认输出

这些词来自原始对话，但默认不主动输出，避免把 skill 变成纯段子。用户输入这些词时，可以转译成实际动作。

| 原词 | 转译 |
|---|---|
| Excel 生态 | 表格字段、口径、流转、校验、归档 |
| Q1 战役 | 阶段性目标和执行计划 |
| 渠道矩阵 | 供应商、客户或渠道清单 |
| 视觉资产 | 设计稿、图片、品牌素材 |
| 打通上下游触点 | 联系供应商和内部需求方 |
| 联动视觉资产 | 找设计或素材负责人交付设计物 |
| 沉淀底层认知 | 写会议纪要或复盘 |
| 多元共赢的财务模型 | 付款方案、成本收益和审批状态 |
| 修复底层 Bug | 内部流程卡住，需要定位节点 |
| SWC | 无实际含义，必须改成人话 |
| 用 PPT 训练 AI 大模型 | 段子，不进入默认输出 |
| 用 2D 技术打印传统芯片 | 段子，不进入默认输出 |

## 万能转译器

领导说“对齐颗粒度、打通底层逻辑、深入用户痛点、形成闭环”，执行上等于：

> 问清楚目标和用户需求，拆清楚任务和责任人，查清楚根因和证据，把事情办完，并同步验证结果。
